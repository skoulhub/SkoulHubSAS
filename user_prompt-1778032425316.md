Design and build a modern, production-ready SaaS dashboard UI for a School Management platform called **SkoulHub**.

---

## 🎨 BRANDING

* Primary color: #1E45FC (blue)
* Accent color: #CDF12B (green)
* Background: #F8FAFF (light), #0B0F2A (dark mode optional)
* Style: clean, modern, minimal SaaS (similar to Stripe, Linear, Notion)

---

## 🏗️ LAYOUT STRUCTURE

* Left sidebar navigation (collapsible)
* Top navbar (search, notifications, profile)
* Main content area (dynamic)
* Responsive (desktop + tablet)

---

## 👥 USER ROLES (ROLE-BASED DASHBOARD)

Design dashboards for:

* SaaS Admin
* School Admin
* Head Teacher
* Teacher
* Parent
* Bursar / Accountant

Each role should see only relevant data and actions.

---

## 📊 CORE DASHBOARD MODULES

1. Overview Dashboard

* Key stats cards:

  * Total students
  * Teachers
  * Attendance rate
  * Revenue
* Charts:

  * Attendance trends
  * Payments overview
* Recent activity feed

---

2. Student Management

* Table view:

  * Name, class, parent, status
* Actions:

  * Add/edit student
  * View profile
* Filters and search

---

3. Teacher Management

* List of teachers
* Assign subjects and classes
* View schedules

---

4. Attendance

* Daily attendance marking UI
* Class selector
* Present/absent toggle
* Save and update in real-time

---

5. Timetables

* School timetable (grid view)
* Teacher timetable
* Prep timetable
* Meal/nutrition schedule

---

6. Academic Results

* Input marks per subject
* Auto-calculation:

  * Total
  * Average
  * Grade
* View student performance

---

7. Report Cards

* Generate mid-term and end-term reports
* Include:

  * Scores
  * Grades
  * Teacher comments
  * Head teacher comments
* Download PDF
* Send via email

---

8. Finance Module

* Payments table:

  * Student, amount, method, date
* Record new payment
* Receipts generation
* Expenses tracking
* Payroll (basic)
* Approval workflow:

  * Accountant submits
  * Head teacher approves/rejects

---

9. ID Cards

* Generate student and teacher ID cards
* Show preview
* Download PDF
* QR code included

---

10. Notifications

* List of system notifications
* Email trigger status

---

---

## 🧠 SaaS ADMIN DASHBOARD

* View all schools (tenants)
* Track:

  * Number of students per school
  * Billing (students × 15000)
* Manage onboarding
* Training content
* Feature requests

---

## 🧪 DEMO / SANDBOX MODE

* Display “Demo Mode” banner
* Disable real payments
* Allow reset of demo data

## 🎯 UI COMPONENTS

* Cards (rounded, shadow)
* Tables (sortable, searchable)
* Tabs and filters
* Modals (forms)
* Charts (bar/line)
* Buttons:

  * Primary: green (#CDF12B)
  * Secondary: outline/blue

---

## ✨ INTERACTIONS

* Hover states (subtle lift)
* Loading states (skeletons)
* Empty states (friendly messages)
* Smooth transitions

## 📊 OUTPUT REQUIRED

* Full dashboard UI design
* Component structure
* Page layouts for each module
* Responsive behavior
* Clean, reusable components

## Create a professional, intuitive SaaS dashboard for **SkoulHub** that is easy to use, visually clean, and scalable for multiple schools and roles.
